# DeepSeek Temperature Lab

Локальное веб-приложение для задания «День 4. Температура». Оно отправляет один и тот же запрос DeepSeek с тремя температурами, показывает ответы рядом и позволяет сравнить каждую тройку только по команде пользователя.

## Что умеет проект

- Использует значения `temperature = 0`, `0.7` и `1.2` по умолчанию.
- Позволяет изменить каждую температуру в диапазоне от `0` до `2` ползунком или точным вводом числа; оба элемента синхронизированы.
- Явно выключает Thinking/Reasoning во всех API-запросах. В Thinking-режиме DeepSeek принимает `temperature` для совместимости, но игнорирует её.
- Не удаляет результаты повторного запуска: новая пачка появляется сверху, старые остаются ниже до обновления страницы.
- Сравнивает только выбранную пачку из трёх успешных ответов и только после нажатия кнопки. Проверяющий запрос использует `temperature = 0`.
- Оценивает точность, креативность и разнообразие, затем объясняет подходящие задачи для каждой использованной температуры.
- Сохраняет выбранную пачку в отдельную подпапку `saved_runs`.

## Установка в Windows

Нужен Python 3.10 или новее. Откройте PowerShell в папке проекта и один раз выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

В `.env` вставьте ключ DeepSeek:

```dotenv
DEEPSEEK_API_KEY=ваш_настоящий_ключ
DEEPSEEK_MODEL=deepseek-v4-flash
```

## Запуск

Дважды щёлкните `run.bat` или выполните:

```powershell
.\run.bat
```

Откроется [http://127.0.0.1:5000](http://127.0.0.1:5000). Остановка сервера: `Ctrl+C` в окне консоли.

Если порт `5000` уже занят старой копией или другой программой, запуск автоматически выберет следующий свободный порт и откроет правильный адрес. Сам `run.bat` содержит только совместимые с `cmd.exe` команды, а русские сообщения выводит Python, поэтому путь к проекту с кириллицей обрабатывается корректно.

## Работа с результатами

1. Введите запрос и при необходимости измените три температуры.
2. Нажмите **«Запустить 3 температуры»**.
3. После получения всей тройки нажмите **«Сравнить три ответа»** у нужной пачки.
4. Нажмите **«Сохранить пачку»**, чтобы записать её на диск.

Каждое сохранение создаёт папку вида:

```text
saved_runs/
└── 2026-09-06_18-30-45_a1b2c3/
    ├── data.json
    └── report.html
```

`data.json` хранит исходные данные, а `report.html` можно открыть обычным браузером без запуска программы. Ссылка **«Сохранённые запуски»** на главной странице показывает архив отчётов.

Если сначала сохранить ответы, а затем выполнить сравнение, первое сохранение останется без анализа. После сравнения нажмите **«Сохранить ещё одну копию»**, чтобы создать полный отчёт.

## Структура

```text
app.py                    Flask-сервер, DeepSeek API, сравнение и сохранение
main.py                   запуск сервера и открытие браузера
templates/index.html      основная страница
templates/saved_runs.html список сохранённых запусков
static/style.css          оформление
static/app.js             запросы, история пачек, сравнение и сохранение
saved_runs/               локальный архив результатов
test_app.py               тесты без обращения к DeepSeek
```

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```

Тесты используют подменённые ответы и не расходуют средства API. Полная проверка качества ответов требует действующего ключа и сетевого доступа.
