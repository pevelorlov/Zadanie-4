# Минимальный клиент DeepSeek API

Проект выполняет задание 1: принимает вопрос, отправляет запрос в LLM через API с выключенным reasoning, получает ответ и выводит его в консоль. После ответа программа отдельно показывает количество входных и выходных токенов, а также их общую сумму.

Reasoning отключается явно в каждом запросе параметром:

```python
extra_body={"thinking": {"type": "disabled"}}
```

## Первоначальная настройка в Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

В `.env` замените значение после `DEEPSEEK_API_KEY=` на свой ключ DeepSeek. Сам файл `.env` никому не передавайте.

## Запуск

После первоначальной настройки выполните:

```powershell
.\run.bat
```

Также можно дважды щёлкнуть по `run.bat` в Проводнике. Программа работает в цикле: после каждого ответа можно ввести следующий вопрос. Для завершения напишите `выход`, `exit` или `quit`, либо нажмите `Ctrl+C`.

Активация `.venv` через `Activate.ps1` не требуется: `run.bat` сам использует правильный Python из виртуального окружения. Поэтому не нужно менять Execution Policy PowerShell.

Можно передать первый вопрос прямо в командной строке:

```powershell
.\.venv\Scripts\python.exe main.py "Объясни простыми словами, что такое API"
```

После ответа программа продолжит ждать следующие вопросы.
